# Sufitowski — wizualizator sufitów napinanych

Сайт-презентация для sufitowski.pl (PL): клиент выбирает комнату, полотно, профиль, свет и карниз и сразу видит результат на фото интерьера. Вечерний режим, сравнение «Przed / Po», ссылка с сохранённой конфигурацией, режим встраивания.

```bash
npm install
npm run dev        # http://localhost:5190
npm run build      # dist/ + пререндер index.html, robots.txt, sitemap.xml
npm run images     # скачать и подготовить фото (public/rooms, catalog, textures, logo)
```

## Как это устроено

- **Фото комнаты + плоскость потолка в перспективе.** Для каждой сцены размечены 4 угла потолка (`src/data/scenes.js`). Из них считается гомография (`src/engine/homography.js`) → CSS `matrix3d`. Всё «на потолке» (полотно, профиль, споты, линии LED, шины, ниша карниза) рисуется в метрах на плоскости, перспектива получается автоматически.
- **Светотень.** `src/engine/shading.js` берёт яркость старого потолка с фото, убирает мелкие детали (споты, шины) и размывает — новое полотно умножается на эту карту, поэтому выглядит освещённым так же, как в оригинале.
- **Глянец.** Зеркальная копия фото относительно стыка со стеной, обрезанная по потолку, с затуханием (сила/размытие — `OPTICS` в `CeilingView.jsx`).
- **Вечер.** Сцена затемняется, поверх в режиме `screen` рисуются светящиеся элементы и ореолы; яркость комнаты зависит от количества света.
- **Каталог** (`src/data/catalog.js`) — id совпадают с калькулятором на sufitowski.pl (`gloss`, `shadowStandard`, `spotStd`, `hiddenLux`…), фото опций взяты оттуда же.

## Параметры адреса

`?s=` сцена · `m` полотно · `c` цвет · `n` надрук · `p` профиль · `k` карниз · `o` тип спотов · `os` вид · `on` количество · `l` лампа · `ll` линии LED · `sm` магнитная шина · `t` температура · `v=night` вечер.
`?embed=1` — только конфигуратор (для вставки через iframe). `?editor` — редактор разметки сцен.

## Как заменить / добавить фото комнаты

1. Положить фото в `public/rooms/<id>.webp` (ширина 1600) и миниатюру `<id>-sm.webp` — или указать id Unsplash в `scripts/images.js` и запустить `npm run images`.
2. Открыть `/?editor`, загрузить фото («Własne zdjęcie»), перетащить 4 точки на углы потолка (0–1 — стык с дальней стеной; передние точки 2–3 обычно за кадром, на продолжении боковых кромок), задать размеры, окно, зону светильников, окклюдеры (шкафы до потолка).
3. «Kopiuj JSON» → добавить объект в `scenes` в `src/data/scenes.js`.

## Открытые вопросы

- Реальный ассортимент (бренды полотен, палитра цветов, модели светильников) — сейчас базовый каталог.
- Адрес, по которому будет жить презентация (`brand.siteUrl` в `src/config.js`), и передача конфигурации в калькулятор (`brand.calcUrl`).
- Фото реальных объектов вместо Unsplash (нужен широкий кадр, где виден потолок и хотя бы две его кромки).
